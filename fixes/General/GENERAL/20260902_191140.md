## Initial Power Check

Start by checking the LED status on the front panel. The LED shows "On/Off: The device is powered on/off" and "Blinking: The device is working properly" or "Off: The device is not working properly". If the LED is off, verify your power connection:

1. **Check AC power** - The unit accepts AC power of 100-240V 50/60Hz. Make sure the unit is plugged into a working outlet and that the power switch is in the ON position.

2. **Verify cable connections** - WyreStorm recommends using a cable tester or connecting the cable to other devices to verify functionality.

## Network/Control Access

If the matrix is powered on but unresponsive to control:

1. **Access via Web UI** - Connect the matrix to the same network as a PC and access the embedded Web UI for configuration and troubleshooting.

2. **Network detection** - In DHCP mode, if the matrix is not connected to DHCP server, the matrix will generate a local 169.254 IP address. By default, the IP type is set as DHCP.

## Factory Reset Option

If you continue having issues: Click "Factory Reset" and then click "OK" in the pop-up window through the Web UI to restore factory defaults.
