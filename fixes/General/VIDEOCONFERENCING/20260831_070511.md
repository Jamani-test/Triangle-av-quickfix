# Yealink MeetingBar Options

Triangle Limited supports the following Yealink MeetingBar models:

## Android-Based MeetingBar Series

| Model | Room Size | Key Features |
|-------|-----------|--------------|
| **A10** | 2–5 people (Home Office/Focus Room) | Entry-level all-in-one bar |
| **A20** | Small rooms | Small room solution |
| **A30** | Medium spaces | Dual-camera design |
| **A40** | Small-to-medium rooms | Dual-eye bar, next-generation AI-enhanced |
| **A50** | Medium-to-large rooms | Triple 50MP camera system, 10m voice pickup, AI-enhanced audio/video |

## Key Capabilities (All Models)

- Integrated camera, microphone, and speaker in single unit
- Fully certified Microsoft Teams Rooms devices
- One-touch join and calendar sync
- Centralized admin portal support
- Multi-platform flexibility with BYOD support

All models feature mounting brackets and are supplied with necessary installation hardware (power adapters, cables, mounting components, cable ties).

**Note:** Some optional packages (VCR11 remote, additional cables) are available separately depending on your deployment needs.
