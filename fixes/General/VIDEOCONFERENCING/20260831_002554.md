# Yealink MeetingBar A50 with CTP25 Setup

## Hardware Connection

1. **Connect CTP25 to A50** using a network cable (Cat5e). This single cable provides both power and network connectivity to the control panel.
2. **Ensure both devices are on the same LAN** — this is a requirement for operation.

## Installation Steps

### A50 Mounting
1. Determine mounting position with recommended height of **110 cm above ground**.
2. If mounting below a TV, maintain the A50 camera **10-20 cm above desk height**.
3. Mount the A50 to the wall, keeping the front flush with the wall surface.
4. Refer to the bracket adjustment section to adjust camera tilt as needed.

### CTP25 Positioning
- CTP25 can be mounted on desk or wall (flexible installation options).

## Configuration & Pairing

1. If using a bundle package, A50 and CTP25 **pair automatically**.
2. If not pre-paired, enter the A50's IP address and pairing code on the CTP25.
3. **Simplified single login**: Once paired directly, you only need to log in once.

## Enable BYOD (Bring Your Own Device)

1. Go to the web interface: System > UC Provider
2. Enable BYOD
3. Connect CTP25 to your PC via USB-C cable and follow the prompts to enter BYOD mode.

**Note:** Both sources confirm the network cable connection requirement and automatic pairing for bundles. No conflicting information between sources.
