## Issue
How do I setup the Yealink MeetingBar A50 with CTP 25?

## Resolution
# Yealink MeetingBar A50 with CTP25 Setup

## Hardware Connection

1. **Connect CTP25 to A50** using a network cable. This provides both power and network connectivity to the touch console.
2. **Ensure both devices are on the same LAN** — this is a requirement for operation.

## Pairing

**Automatic Pairing:**
- If you purchased a combination kit, the CTP25 and A50 pair automatically.

**Manual Pairing** (if purchased separately):
1. On the CTP25 display, enter the A50's IP address
2. Enter the pairing code (displayed on the screen connected to the A50)

## Initial Configuration

During startup, initialize:
- Language
- Network settings (wired or wireless)
- Time zone
- Auto Update setting
- Desired platform/mode

## Enable BYOD Mode (if required)

1. Go to the web interface: enter the A50's IP address in your browser (e.g., `https://10.82.24.11/`)
2. Login with default credentials (username: "admin", password: "0000")
3. Navigate to **System > UC Provider**
4. Enable BYOD
5. Use a USB-C cable to connect the CTP25 to your PC and follow prompts

## Firmware Updates

Update A50 and CTP25 **separately**:
1. Obtain each device's IP address
2. Open browser and enter IP (e.g., `https://10.82.24.11/`)
3. Login (admin / 0000)
4. Go to **System > Update**
5. Click **Select File** and upload firmware
6. Click **Update**

Get latest firmware at https://support.yealink.com/
