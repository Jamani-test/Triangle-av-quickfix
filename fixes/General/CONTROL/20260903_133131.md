## Resolution
# Control4 CORE 5 Update Timeout Troubleshooting

**The 120-minute timeout indicates the update process lost network connectivity or couldn't complete the download within that timeframe.**

## Immediate Actions

**1. Verify Network Connectivity (Critical)**
- Confirm Ethernet cable is firmly seated in the RJ-45 ETHERNET port on the back of the CORE 5
- Test network stability — check for packet loss, latency spikes, or intermittent drops
- Verify firewall/router isn't blocking Control4 update servers
- Per documentation: network connection is *required* for all CORE 5 features; Ethernet is recommended over Wi-Fi for reliability

**2. Power Cycle the Controller**
- Unplug the AC power cord from the power plug port (IEC 60320-C13)
- Wait 5 minutes
- Reconnect and allow 2-3 minutes for full boot (watch LED indicators: Caution LED solid red → blue flash during boot; Link LED should go solid blue once connected to Director)

**3. Check Controller Status Before Retry**
Review LED indicators on the front:
- **Power LED** — must be solid blue
- **Link LED** — must be solid blue (indicates Director connection established)
- **Caution LED** — should not be flashing

**4. Retry the Update**
Attempt the update again after stable network connection is confirmed.

## Alternative Methods

- **USB Drive Update** — If network connectivity remains unstable, try downloading the update to a USB drive and updating locally (CORE 5 supports external USB storage via the two USB 2.0 ports)
- **Different Network** — Test update on an alternate network connection if available

If the update continues to fail:
