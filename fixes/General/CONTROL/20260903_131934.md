# How to Know Your CORE 5 is Updating

Based on the Control4 CORE 5 documentation, here's how to identify update status:

## LED Indicator Method (Primary)

Monitor the **ID button on the back of the controller**. During a software update, the ID button displays:

- **1 flash per 2 seconds** = Update in progress
- **1 flash per 2 seconds (alternating pattern)** = Update error occurred

The front **Caution LED** provides the same feedback as the ID button during this process.

## Additional Status Indicators

- **Link LED** (solid blue) = Connected to Director
- **Power LED** (solid blue) = AC power connected
- **Activity LED** = Streaming audio

## Network Verification

You can also confirm update activity by:
1. Checking the controller's network connectivity (Ethernet or Wi-Fi must be active)
2. Accessing **OvrC** (www.ovrc.com) for remote monitoring if configured
3. Using **Composer Pro System Manager** to view system status

---

**Note:** The controller requires an active network connection to receive and install updates. Ensure your CORE 5 is connected via Ethernet (recommended) or Wi-Fi before expecting updates.

If you see the error flash pattern, escalate to Control4 Technical Support: ctrl4.co/techsupport
