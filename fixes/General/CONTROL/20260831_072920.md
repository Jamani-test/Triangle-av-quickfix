# Wyrestorm MX0808 Control4 CORE 3 Network Control Troubleshooting

Based on the documentation, here's how to resolve your control issue:

## Network Setup Requirements

1. **Verify network connectivity**
   - Connect the MX0808 LAN port directly to your network switch/router using a straight-through Ethernet cable
   - Confirm the matrix has a static IP address (default: 192.168.11.143)
   - Ensure your CORE 3 and MX0808 are on the same subnet (192.168.11.0/24 or similar)

2. **Confirm Control4 driver installation**
   - The CORE 3 requires a Control4 driver for the MX0808 to enable network control via TCP/IP
   - No additional hardware interface is needed—communication occurs over Ethernet
   - Verify the correct driver is installed in Composer Pro using Auto Discovery and SDDP

## CORE 3 Network Configuration

Per the documentation, your CORE 3 requires:
- **Ethernet connection**: Connect to RJ-45 port labeled **ENET/POE+ IN** (required for setup and optimal performance)
- The CORE 3 includes 2 × 10/100/1000BaseT compatible ports acting as a network switch

## Next Steps

1. Verify both devices can ping each other across the network
2. Check Composer Pro to confirm the MX0808 driver is added to your project
3. If the driver isn't available, contact Wyrestorm support for the Control4-compatible driver file for your specific MX0808 model variant

**Note**: The manufacturer documentation for driver-specific configuration is not included in our available materials. Consult ctrl4.co/cpro-ug for Composer Pro setup details.
