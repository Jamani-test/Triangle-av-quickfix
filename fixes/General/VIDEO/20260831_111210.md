## Resolution
# MX0808 Kit V2 - No Video Troubleshooting

Follow these steps in order:

## 1. Power & LED Status
- Check the matrix power LED is solid (powered on) or blinking (operational)
- If LED is off, device is not powered—verify power supply

## 2. Connection Verification
- Confirm power is supplied to both the matrix and HDBT receiver
- Verify all HDMI and HDBaseT connections are fully seated and secure (no loose cables)

## 3. Video Routing Configuration
- Access the Web UI through your browser (Chrome, Firefox, Safari, Opera, IE)
- Connect the matrix LAN port to your network, or directly to your PC with a straight UTP cable
- In the Video Matrix Control section, verify the correct input is routed to the correct output
- By default: INPUT 1→OUTPUT 1, INPUT 2→OUTPUT 2, etc.
- Click the input/output button to route your source to the display output
- The button should turn green when selection is confirmed

## 4. Cable Quality & Standards
- Use **Cat 6a/7 HDBaseT cable** (not standard Cat 5e)
- For 4K sources: use 4K-rated HDMI cables
- Remove kinks, avoid patch panels/wall plates during testing, minimize electrical interference
- **HDBaseT transmission distances:**
  - 4K@60Hz 4:2:0 8bit: up to 40m (131ft)
  - 1080p: up to 70m (230ft)

## 5. Resolution Compatibility
- Verify source and display both support resolutions up to **4K@60Hz 4:2:0 8bit** (maximum supported)
- Confirm HDCP 2.2 compatibility if using protected content

## 6. Advanced Diagnostics
- Use **Video Details** in Web UI to check connection status, signal, and resolution of each port
- For RS232 control (if using Control4 or similar), configure: 9600 baud, 8 data bits, no parity, 1 stop bit
