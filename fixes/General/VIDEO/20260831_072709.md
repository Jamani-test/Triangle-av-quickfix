# MX-0808 KIT Source Switching Troubleshooting

Here's how to diagnose and fix your source switching issue:

## 1. Verify Basic Operation
- Power on the matrix and wait for the front panel LED to display input channel numbers corresponding to output channels
- The matrix is ready when the LED stabilizes (stops blinking)

## 2. Front Panel Control Method
If using front panel buttons:

1. Press **Left (◄) or Right (►)** to select output channel — LED will blink
2. Press **Up (▲) or Down (▼)** to select input channel
3. **Press ENTER to confirm** — this is critical; selection will not take effect without pressing ENTER
4. When the selection is complete, the LED stops blinking

## 3. Verify Connections
- Check all HDMI and HDBaseT connections are secure and not loose
- Verify power supply to both matrix and receiver
- Minimize cable issues: avoid kinks, patch panels, wall plates, and electrical interference

## 4. Check Resolution Compatibility
- Confirm both source and display support the same resolution
- If using 3D or 4K content, verify your HDMI cables are rated for those standards

## 5. IR/RS-232 Control
- If using IR control, verify IR and RS-232 cables are properly terminated
- Use WyreStorm infrared emitters/receivers for best compatibility
