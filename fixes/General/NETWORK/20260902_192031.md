## Issue
How do I reset my Araknis router

## Resolution
# Araknis Router Reset Procedures

The reset button is located on the back of the router. Here are your reset options:

## Soft Reset (Restart)
**Hold the reset button for 1-9 seconds**
- Front LED: Blinking slowly
- Result: Router restarts without changing settings

## Password Reset
**Hold the reset button for 10-19 seconds**
- Front LED: Blinking moderately
- Result: Resets username and password to factory defaults
- **Note:** The Password Reset function must be enabled in the router's local interface for this to work

## Factory Reset (Hard Reset)
**Hold the reset button for 20+ seconds**
- Front LED: Blinking rapidly
- Result: All settings return to factory defaults (WiFi name/password, ISP settings, port forwards, firewall rules, etc.)
- **Caution:** The current firmware version will not change, but all configuration data will be permanently lost

**Recommendation:** Back up your configuration before performing a factory reset using the File Management page (Maintenance > File Management > Configuration File).
