# Sonos Amp Audio Dropouts During AirPlay & Line-In: Root Causes & Solutions

## Primary Causes

**1. WiFi Connectivity Issues**
This is the most common culprit for line-in dropouts. Environmental interference (microwaves, baby monitors, other 2.4GHz devices) disrupts the signal between your audio source and the Amp. AirPlay compounds this since it's also WiFi-dependent.

**2. Firmware Bug (Confirmed)**
Sonos has acknowledged a software bug causing audio dropouts in multichannel setups. This explains why updates provide *temporary* relief—the underlying issue recurs.

**3. Network Configuration Problems**
- Dynamic IP assignment causing reconnection issues
- Buffer underruns on line-in audio (default 70ms buffer too small for uncompressed audio)

## Troubleshooting Steps

1. **Wired connection (recommended first step):**
   - Connect the Amp to your router via Ethernet cable
   - In Settings → Product Settings → Turn off WiFi (reduces power/heat in rack installations and improves wired connectivity)

2. **Line-in specific adjustments:**
   - Access line-in settings and increase Audio Delay buffer from 70ms to 500ms to prevent dropouts on uncompressed audio
   - Verify Source Level isn't clipping or set too quietly

3. **Network optimization:**
   - Set static/reserved IP for the Amp via your router's DHCP page
   - Power cycle: router → Amp → AirPlay source device
   - Reduce WiFi channel width to 20MHz; try different channels

4. **Diagnostic escalation:**
   - Power cycle the Amp (temporary relief confirms the pattern)
   - Submit diagnostic report to Sonos Support—they can identify firmware-specific issues

**Key difference in sources:** Manufacturer docs don't mention the known dropout bug, but Internet source confirms Sonos has publicly addressed this issue.

**Recommendation:** Start with Ethernet + 500ms line-in buffer. If dropouts persist, escalate to Sonos Support with diagnostics.
