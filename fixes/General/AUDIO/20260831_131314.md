## Sonos Amp Analog Audio Skipping — Troubleshooting Steps

### 1. Network & Wireless Connection
Audio skipping on Sonos Amp line-in typically indicates a weak wireless connection:
- Move the Amp closer to your router if it's in a wireless setup
- Check for wireless interference — consider changing wireless channels
- Move the Amp away from electronic devices that may cause interference
- If possible, connect the Amp to your network via Ethernet for a wired connection

### 2. Cable & Source Verification
- Verify all analog cables are properly seated at both ends
- Use high-quality analog cables appropriate for audio input
- If using a turntable, confirm it has a built-in phono preamp

### 3. Firmware & Device Updates
- Ensure Sonos Amp has the latest firmware installed
- Update any connected source devices (turntables, CD players, receivers, etc.)

### 4. Network Hardware Check
- Verify you don't have incompatible network devices causing issues: WiFi extenders, mobile hotspots, or LTE routers

### 5. Diagnostic & Support
If skipping persists after these steps:
- Take a system diagnostic within 10 minutes of the problem occurring
- Contact Sonos Support with the diagnostic and details about which source you're using

**Note:** Line-in connections have an automatic audio delay, but this wouldn't typically cause skipping — focus on network stability first.
